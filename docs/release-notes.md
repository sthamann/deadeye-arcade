# Deadeye Arcade 0.3.33

Starting Deadeye with a connected Blamcon Vyper no longer opens Steam or repeats the ARC installation request. Background setup checks ARC availability and shows the remaining setup step in My Guns. Use Install / open Blamcon ARC to open Steam when you are ready to complete the vendor setup.

The existing automatic setup for other gun systems and explicit ARC installation remain available. ARC setup status is displayed in English or German.
