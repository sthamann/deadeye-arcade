# Deadeye Arcade artwork

The original eye-and-target emblem pairs ivory and bright orange with a dark arcade cabinet finish. The same visual identity is used in the Windows app icon and the matching desktop wallpaper.

- [App icon PNG](../assets/branding/deadeye-icon.png): 1254 × 1254, with transparent corners.
- [Windows ICO](../assets/branding/deadeye.ico): 16, 24, 32, 48, 64, 128 and 256 pixel frames.
- [Desktop wallpaper](../assets/wallpapers/deadeye-arcade.png): 1672 × 941. This is its native generated resolution; it is not advertised as native 4K.

The Windows executable, main window, Setup, uninstaller, desktop shortcut and Start menu shortcut use the new icon. Setup includes `wallpapers/deadeye-arcade.png`. To apply it, right-click that image in Explorer and choose **Set as desktop background**, then choose **Fill** in Windows Personalization if needed. Installing or updating the app does not replace a user's chosen wallpaper.

These original generated branding assets are distributed under the repository's MIT license. They do not include third-party game artwork.

## Generation record

Created with the built-in image generation tool. The ICO only converts the generated PNG to Windows icon frames; its artwork is unchanged.

### Icon prompt

Use case: logo-brand. Asset type: finished Windows desktop application icon for Deadeye Arcade, a premium lightgun arcade launcher. Generate a SINGLE square 1024x1024 icon, not a sheet of variations or a mockup. Subject: a bold stylized eye whose pupil is an arcade aiming target, integrated into a compact unmistakable emblem. A warm ivory eye shape surrounding a vivid electric-orange circular pupil with four short crosshair marks; understated gunmetal dimensional edges, premium enamel/metal craft, sharp silhouette and excellent small-size legibility. Scene/backdrop: one opaque very dark graphite rounded-square tile with subtly beveled corners; genuine transparent alpha outside the rounded tile. Palette: charcoal black, warm ivory, bright arcade orange, very restrained cool teal highlight. Composition: centered emblem occupying 72 percent of tile, strong visual weight, clean and polished, consistent silhouette that still reads at 32x32. A sophisticated arcade-machine badge rather than military insignia. No words, no letters, no guns, no skull, no extra symbols, no frame mockup, no busy texture, no tiny intricate details, no cast shadow outside tile. Output only the finished icon.

### Wallpaper prompt

Use case: stylized-concept. Asset type: finished premium Windows desktop wallpaper for the Deadeye Arcade lightgun gaming PC. Generate one wide 16:9 3840x2160 artwork. Reference image: use only its eye/crosshair emblem and charcoal / ivory / vivid orange / subtle teal visual identity. Do not include its rounded-square app tile. Scene: cinematic dark arcade command room with distant arcade cabinets, black architectural panels, subtle volumetric haze, orange illuminated floor strips and restrained cool teal accent light. Premium photorealistic game key-art treatment, polished materials, depth, moody high contrast. Composition: the left 35 percent is very dark calm negative space, suitable for readable desktop icons; low-detail dark upper area and dark bottom strip for taskbar. Main artwork focused in center-right: a clean ivory stylized eye with bright orange circular crosshair pupil, integrated as a luminous arcade emblem on a large black wall panel. Below emblem, the ONLY readable typography is exact title "DEADEYE" and underneath smaller widely spaced "ARCADE", rendered impeccably in bold custom geometric sans serif, ivory with restrained orange accent. Keep logo and title fully inside central-right 45 percent of frame. Emblem proportion moderate, not a huge full-image eye. Atmospheric arcade cinema, impressive and mature, refined rather than cluttered neon. Avoid other text, slogans, UI mockups, desktop icons, Windows logos, private information, game characters, guns, skulls, watermarks. Output the wallpaper itself edge to edge.

The generated icon was supplied as the visual reference for the wallpaper. The tool returned the native resolutions listed above.
